# Peashooter

Select Peashooter in any squad slot. Human and AI control use the same character simulation, weapon and abilities.

| Control | Action |
| --- | --- |
| Left mouse | Pea Cannon; hold to fire at its normal cadence |
| Right mouse | Aim |
| R | Reload the 10-pea magazine |
| Q | Throw a Chili Bean Bomb toward the aim point |
| E | Root into Pea Gatling; press E again to uproot |
| F | Activate Hyper |
| Space during Hyper | Boosted jump |

The cannon deals direct impact damage and a separate splash; nearby targets receive only splash. Splash uses vertical distance and cover checks. Gatling fires rapid, precise peas from a separate 100-round supply, requires a deployment pause and prevents moving or jumping. Its recovery starts on uprooting, expiry, or exhausting its rounds. Hyper increases movement speed and jump height for eight seconds. The bean follows a physical arc, collides with cover, bounces to rest, attracts zombies, pulses and ticks before exploding. All geometry and audio are generated in code; there are no model, image texture, or audio sample downloads.

The reference image guided the hollow trumpet muzzle, glossy jade eyes, yellow-green head, folded leaf crown, narrow stalk, open pea pods, curling vines and broad leaf feet. The rig animates breathing, weighted strides, leaning, landing compression, reload motion, recoil, blinking and leaf movement. Gatling adds a helmet, rotating barrels and ground braces. Fine rind relief is generated by the material shader.

`CONFIG.PLANTS.peashooter` owns health, primary and ability tuning; `CONFIG.PEASHOOTER` owns visual and AI tuning. The shared Q/E/F action slots retain their internal Corn keys so the squad controller and HUD can dispatch each plant's own implementations. Active ability state and ammunition remain on the character during a control handoff; death removes the active modes and respawn restores the character.

## Companion behavior

Peashooter patrols roughly 18–33 metres from the garden and pulls engagements back within its 40-metre guard area. Splash opportunities raise a target's priority; an approaching bomber can override that preference. It checks the throw arc to a cluster centroid before spending a bean, uses Hyper for long travel or escape, and roots for Gatling against bosses or armored targets with enough space around it. Nearby danger triggers uprooting immediately; brief target gaps preserve a short firing commitment. Low health prompts a retreat toward the garden. Decisions run at the shared AI think rate, with clustered-target counts refreshed separately.

## Reference and validation

[EA's Garden Warfare 2 PC manual](https://eaassets-a.akamaihd.net/eahelp/manuals/pvz-garden-warfare-2-manual_PC_na.pdf) confirms Pea Cannon, Chili Bean Bomb, Pea Gatling and Hyper. This is an independently implemented adaptation of those mechanics to Garden Defense. Damage, timing, movement and AI thresholds are tunable values for this game.

`node tests/peashooter.cjs` runs browser scenarios using Playwright. The test dependency is separate from the game's single-file runtime. Set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` if using a nondefault browser executable. The browser must be able to load the game's existing three.js CDN imports. Optionally set `PEASHOOTER_SCREENSHOTS` to an output directory for normal and deployed Gatling previews.

Scenarios cover direct versus splash damage, splash range, boosted movement and jumping, rooted firing and separate ammunition, manual uprooting/cooldown, bean landing/lure/cluster kills, group prioritization, boss commitment, danger escape, low-health retreat, middle patrol, state retention across switching, death/respawn, HUD labels and browser/shader errors.
